### 4. Content Inventory Highlights & Migration Risk Register

Full row-by-row details for all 60 audited items (46 posts, 5 pages, 8 root/generated endpoints, and the 107 tag archive routes) are recorded in [`MIGRATION_INVENTORY.csv`](./MIGRATION_INVENTORY.csv).

#### Critical Findings & Risks

1. **Filename Date vs. Front-Matter Date Mismatches (4 Posts)**
   Jekyll routes posts by **front-matter `date`**, not filename prefix. Four posts have mismatched dates; preserving live URLs requires honoring front-matter `date`:
   - `_posts/2019-10-15-ai-art-gallery.md` (`date: 2019-09-01`) → `/blog/2019/09/01/ai-art-gallery.html`
   - `_posts/2021-11-10-nanogenmo-2021.md` (`date: 2021-10-09`) → `/blog/2021/10/09/nanogenmo-2021.html`
   - `_posts/2024-03-02-llm-pruning-finetuning.md` (`date: 2024-05-31`) → `/blog/2024/05/31/llm-pruning-finetuning.html`
   - `_posts/2024-05-31-fuzzy-matching-in-python.md` (`date: 2024-03-02`) → `/blog/2024/03/02/fuzzy-matching-in-python.html`

2. **Slug & Filename Anomalies (2 Posts)**
   - `_posts/2020-11-30-nanogenmo-2020-.md`: Trailing hyphen in filename is stripped by Jekyll's slugifier → live URL is `/blog/2020/11/30/nanogenmo-2020.html`.
   - `_posts/2019-03-25-democritization-of-expertise.md`: Contains typo `democritization` in filename/URL → live URL `/blog/2019/03/25/democritization-of-expertise.html` MUST be preserved (also linked from the `2022-09-06` post).

3. **Draft Posts Leak into `_site/` and `sitemap.xml` (2 Posts)**
   - `_posts/2022-12-08-ai-alignment-for-business-owners.md` (`draft: True`, 43 words)
   - `_posts/2023-01-21-supply-chain-network-design-python-pulp.md` (`draft: true`, 5,032 words, Jupyter HTML/Pandas `<style scoped>` blocks)
   Both are excluded from `blog.html`, `feed.xml`, `search.json`, and `tag_gen.rb`, **but** Jekyll still built HTML pages for them in `_site/blog/...` and included them in `_site/sitemap.xml`. *(See Blockers/Decisions #2.)*

4. **Broken Windows Local `file:///` Links in Published July 2026 Posts (2 Posts, 4 Links)**
   - `_posts/2026-07-28-the-most-expensive-question-in-ml.md` lines 225 and 251 link to `file:///c:/Users/natur/Downloads/projects/victorangeloblancada.github.io-jekyll/_posts/...`.
   - `_posts/2026-07-31-lean-six-sigma-ai.md` line 208 has two links to `file:///c:/Users/natur/Downloads/posts/...`.
   *(In Stage 4, a remark compatibility rule or explicit verified link fix can map these cleanly to their `/blog/2026/...` URLs without changing prose.)*

5. **Mathematical Typesetting Heterogeneity (14 Posts)**
   Fourteen posts embed `<script type="text/javascript" async src="https://cdnjs.cloudflare.com/ajax/libs/mathjax/2.7.5/latest.js?config=TeX-MML-AM_CHTML"></script>`:
   - **11 posts** use TeX `$$...$$` for both inline and block math (note: 2 of those—`2026-07-21` (`$W_t$`) and `2026-07-28` (`$N$`)—also have 1 single-`$` inline expression each, while 5 other posts use single `$` purely for currency like `$400MM`, `$30,000 to $40,000`, `$110`).
   - **1 post** (`2022-03-20-finance-from-first-principles.md`) relies on **AsciiMath inside 79 backtick code spans** (e.g., `` ` FV = PV(1+r)^n ` ``) rendered by MathJax `TeX-MML-AM_CHTML` (`AM` = AsciiMath), and also contains an HTML-commented calculator widget (`<!--<script>...-->`).
   - **2 posts** (`2026-07-17` and `2026-08-06`) include the MathJax `<script>` tag with zero formulas.
   **Migration impact:** Using `remark-math` with default single-`$` enabled would break currency strings (`$30,000 to $40,000`). We must configure `{ singleDollarTextMath: false }` (or protect currency `$`), handle `$W_t$`/`$N$` cleanly, and convert or render the 79 AsciiMath expressions in `2022-03-20-finance-from-first-principles.md` (either build-time AsciiMath-to-TeX transform into KaTeX or `asciimath2tex` in the remark pipeline so no post requires client-side MathJax 2.7.5).

6. **Liquid Tags & Kramdown Syntax in Posts (8 Posts)**
   - **5 posts** use `{% post_url ... %}`: `2019-07-01-diy-site-development.md`, `2026-07-16-the-pot-and-the-tree-what-apple-sees-in-bonsai.md`, `2026-07-17-when-agents-hunt-agents-the-hugging-face-intrusion.md`, `2026-07-21-test-time-training-dynamic-adaptation.md`, `2026-07-23-the-recursion-turns-on-itself-autoresearch.md`.

## Part II — Stage 2: Proposed Astro Architecture & Migration Plan

### 1. Target Technology Stack
- **Static Site Generator:** Astro 5.x (`output: 'static'`)
- **Site / Base / Trailing Slash:** `site: 'https://victorangeloblancada.github.io'`, `base: '/'`, `trailingSlash: 'ignore'` (allowing explicit `.html` file routes alongside directory `/index.html` routes)
- **Language & Styling:** TypeScript (strict), semantic HTML5, modern CSS (custom properties, CSS Grid/Flexbox, container queries, `:has()`, `prefers-reduced-motion`, `@media print`)
- **Markdown / MDX Pipeline:**
  - `remark-jekyll-compat` (custom build-time AST plugin)
  - `remark-math` (`{ singleDollarTextMath: false }`) + `rehype-katex` (build-time math rendering with zero client-side MathJax runtime)
  - Built-in **Shiki** (dual light/dark themes + copy-code enhancement)
  - `@astrojs/mdx` (used selectively only when an article embeds interactive Astro/client components)
- **Search:** **Pagefind** (`npx pagefind --site dist`) indexed strictly on `<main data-pagefind-body>` (excluding nav, footer, TOC chrome, and 404), supporting `Cmd/Ctrl + K` modal + dedicated `/search/` page + type/category/tag facets
- **Feeds & SEO:** `@astrojs/rss` (`/feed.xml`), `@astrojs/sitemap`, canonical `<link>`, Open Graph / Twitter metadata, JSON-LD `Article` / `Person` schema, `public/robots.txt`
- **Visualization & Motion (Per-Page Lazy Loaded Only):** D3.js (clustering / charts), Canvas 2D / WebGL (generative network), GSAP (only on complex coordinated timelines when justified), Three.js (only on 3D lab experiments when justified). Zero JS shipped on standard Markdown articles beyond lightweight progressive enhancement (theme toggle, copy-code, search trigger).

### 4. Exact URL Preservation & Redirect Strategy

| Legacy Route Pattern | Astro Strategy | Notes |
| --- | --- | --- |
| `/blog/YYYY/MM/DD/<slug>.html` | Generated verbatim by `src/pages/blog/[...slug].astro` | Computes `YYYY/MM/DD` from **front-matter `date`**, strips trailing `-` on `nanogenmo-2020`, preserves `democritization-of-expertise`. Exact `.html` output (`build.format: 'file'` or explicit `.html` route param) guarantees 1:1 parity on GitHub Pages without redirects. |
| `/pages/<name>.html` | Generated verbatim by `src/pages/pages/[slug].astro` | Preserves all 5 `/pages/*.html` URLs; clean routes like `/about/` can redirect or alias with canonical pointing cleanly. |

### 6. Interactive Component Architecture

- **Zero-framework core:** Standard Astro islands/components render static HTML + progressive-enhancement `<script>` modules with `data-demo="..."` mount targets.
- **Lazy Loading:** Heavy libraries (`d3`, `three`, `gsap`) are dynamically imported (`await import(...)`) only inside the specific component chunk or via `IntersectionObserver` when scrolled near the viewport.
- **Cross-Component Event Bus:** Lightweight `CustomEvent` helper (`src/components/interactive/eventBus.ts`) enabling sibling components (e.g., parameter controls, chart canvas, live metrics readout) to stay synchronized without React/global state bloat.
- **Resilience:** Every experiment provides a static SVG/HTML fallback inside `<noscript>` or initial server-rendered DOM, responsive resize observers, keyboard accessibility (`role="slider"`, `aria-valuetext`, focus-visible rings), and automatic pause/static rendering under `prefers-reduced-motion: reduce`.
